┌──────────┬──────────────────────┬──────────────────────────────┬──────────┐

│    ①     │ M8.ROW_ADDR[3:0]     │ DM1.行选择 (南侧, 4bit)       │  4bit    │

│    ③     │ M3.car_pos[3:0]      │ M8.CAR_COL[3:0]              │  4bit    │
│    ④     │ M4.OBS_COL[3:0]      │ M8.OBS_COL[3:0]              │  4bit    │
│    ⑤     │ M4.OBS_ROW[3:0]      │ M8.OBS_ROW[3:0]              │  4bit    │

└──────────┴──────────────────────┴──────────────────────────────┴──────────┘

每条走线规则:
  ①: M8右侧ROW_ADDR引脚 → 正交拐弯 → DM1南侧行选择脚
  ②: M8右侧COL_DATA引脚 → 正交拐弯 → DM1西侧列数据脚
  ③: M3边界car_pos引脚 → 正交拐弯 → M8左侧CAR_COL引脚
  ④: M4边界OBS_COL引脚 → 正交拐弯 → M8左侧OBS_COL引脚 (需先在model4添加此输出)
  ⑤: M4边界OBS_ROW引脚 → 正交拐弯 → M8左侧OBS_ROW引脚
  ⑥: BTN1输出 → 正交拐弯 → M8左侧RST引脚
