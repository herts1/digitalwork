# =====================================================================
#  根因诊断: 比较器信号接反了 (交叉接线)
# =====================================================================

randon_design 内部有两个比较器和两个MUX，但它们的连接是交叉的：

  ┌──────────────────────────────────────────────────────────────┐
  │                    当前接线 (错误)                            │
  │                                                              │
  │  CMP1 (670,850)           CMP2 (670,910)                     │
  │  比较: SCAN_row==goal_row  比较: SCAN_row==0xF               │
  │  含义: "是否=障碍物行?"    含义: "是否=第15行(小车行)?"       │
  │       │                         │                            │
  │       │   ┌─────────────────────┘                            │
  │       │   │                                                  │
  │       ▼   ▼                                                  │
  │     ┌─────────┐          ┌──────────┐                        │
  │     │ MUX1    │          │ MUX2     │                        │
  │     │ (610,   │          │ (1030,   │                        │
  │     │  1110)  │          │  1110)   │                        │
  │     │         │          │          │                        │
  │     │ data1 = │          │ data1 =  │                        │
  │     │ CAR列   │          │ OBS列    │                        │
  │     │ sel  =  │          │ sel  =   │                        │
  │     │ 障碍行? │ ✗        │ 小车行?  │ ✗                      │
  │     └────┬────┘          └────┬─────┘                        │
  │          │                    │                               │
  │          ▼                    ▼                               │
  │      小车列@障碍物行     障碍物列@第15行                       │
  │      ↑ 小车跟随障碍物！  ↑ 障碍物在底部！                      │
  └──────────────────────────────────────────────────────────────┘

正确逻辑应该是:
  - MUX1 (car MUX): data1=小车列, sel=小车行匹配? → 小车亮在第15行
  - MUX2 (obs MUX): data1=障碍物列, sel=障碍物行匹配? → 障碍物亮在它的行

但当前接线是反的:
  - MUX1 sel 接了 CMP1(障碍物行匹配) → 小车亮在障碍物行 ← 你看到的问题!
  - MUX2 sel 接了 CMP2(小车行匹配)   → 障碍物亮在第15行
