# =====================================================================
#  第三章: 修复方案 (8步操作, 在Logisim GUI中完成)
# =====================================================================

步骤概览:
  ① 删除 Decoder (800,320) 和 Splitter (860,320) — 冗余
  ② 删除悬空死胡同导线 (x=520 附近的4条断头线)
  ③ model2 SRC_PIN → model4 OBS_SRC
  ④ model3 car_pos → randon_design car_clo
  ⑤ model4 COL_Q → randon_design goal_col
  ⑥ model4 ROW_q → randon_design goal_row
  ⑦ randon_design row_Q → DotMatrix 行选择(南侧)
  ⑧ randon_design 16bit输出 → DotMatrix 列数据(西侧)

详细操作:

【步骤①】删除冗余器件
  选中 Decoder (800,320)，按 Delete
  选中 Splitter (860,320)，按 Delete
  同时删除与它们相连的全部导线 (820,160~310)→(880,160~310)
  以及 (860,350)→(1070,350)→(1070,420)→(1140,420)→(1140,360)

【步骤②】清理悬空导线
  删除以下4条死胡同导线 (都汇聚在 x=520 无后续连接):
  - (350,380)→(520,380)   model3 car_pos 死胡同
  - (490,360)→(520,360)   model4 输出死胡同
  - (510,400)→(520,400)   model4 输出死胡同
  - (470,340)→(520,340)   Pin 死胡同
  保留 (230,490)→(250,490) 待用

【步骤③】model2 → model4
  源:  model2 SRC_PIN 引脚 (model2右侧边界, 标签"SRC_PIN", 4bit)
  目标: model4 OBS_SRC 引脚 (model4左侧边界, 标签"OBS_SRC", 4bit)
  路由: 从 model2 右侧水平至 (280,490)，垂直至 model4 OBS_SRC 同Y，
        水平接入引脚

【步骤④】model3 → randon_design
  源:  model3 car_pos 引脚 (model3右侧边界, 标签"car_pos", 4bit)
  目标: randon_design car_clo 引脚 (randon_design左侧, 标签"car_clo", 4bit)
  路由: 从 model3 右侧水平至 (620, car_pos_Y)，垂直至 randon_design，
        水平接入 car_clo 引脚

【步骤⑤】model4 COL_Q → randon_design goal_col
  源:  model4 COL_Q 引脚 (model4右侧边界, 标签"COL_Q", 4bit)
  目标: randon_design goal_col 引脚 (randon_design左侧, 标签"goal_col", 4bit)
  路由: 从 model4 COL_Q 水平至 (680, col_q_Y)，
        垂直至 randon_design goal_col 同Y，
        水平接入 goal_col 引脚

【步骤⑥】model4 ROW_q → randon_design goal_row
  源:  model4 ROW_q 引脚 (model4右侧边界, 标签"ROW_q", 4bit)
  目标: randon_design goal_row 引脚 (randon_design左侧, 标签"goal_row", 4bit)
  路由: 从 model4 ROW_q 水平至 (680, row_q_Y)，
        垂直至 randon_design goal_row 同Y，
        水平接入 goal_row 引脚

【步骤⑦】randon_design row_Q → DotMatrix 行选择
  源:  randon_design row_Q 引脚 (randon_design右侧, 标签"row_Q", 4bit)
  目标: DotMatrix (1180,350) 南侧行选择端 (4bit)
  路由: 从 randon_design row_Q 水平至 (1050, row_q_Y)，
        垂直至 (1050,350)，水平至 (1180,350)

【步骤⑧】randon_design 16bit输出 → DotMatrix 列数据
  源:  randon_design 16bit输出引脚 (randon_design右侧, 16bit, 无标签)
  目标: DotMatrix (1180,350) 西侧列数据端 (16bit)
  路由: 从 randon_design 16bit引脚水平至 (1060, col_data_Y)，
        垂直至 (1060,360)，水平至 (1180,360)
