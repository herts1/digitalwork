╔══════════════════════════════════════════════════════════════╗
║  🔴 错误1: Adder A输入接的是 OBS_COL.Q 而非 OBS_ROW.Q       ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║ 证据链:                                                      ║
║   (470,610) → (500,610) → (530,610) = Adder A输入           ║
║   (470,610) 同时经 (500,510) → COL_Q输出(800,510)           ║
║                                                              ║
║   COL_Q = "Column Q" = 障碍物列值 → (470,610) = OBS_COL.Q   ║
║                                                              ║
║ 结果: Adder计算 OBS_COL + B, 而非 OBS_ROW + B               ║
║       OBS_ROW 被赋予列的值, 不是行的值                       ║
║                                                              ║
║ 应有接线: OBS_ROW.Q(670,610) ──反馈──→ Adder.A(530,610)     ║
╚══════════════════════════════════════════════════════════════╝

╔══════════════════════════════════════════════════════════════╗
║  🔴 错误2: Adder B输入 = 0, 应为 1                           ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║ 证据:                                                        ║
║   Constant(490,630): 无value属性 → 默认值 = 0x0              ║
║   (490,630) → (530,630) = Adder B输入                       ║
║                                                              ║
║ 结果: Adder计算 A + 0 = A (不增加)                           ║
║       即使A接对了, 也只是 OBS_ROW + 0 = 不变                 ║
║                                                              ║
║ 应有: Constant value=0x1 → Adder计算 A + 1                  ║
╚══════════════════════════════════════════════════════════════╝

╔══════════════════════════════════════════════════════════════╗
║  🟡 错误3: OBS_ROW 无反馈回路                                 ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║ OBS_ROW.Q 在 (670,610), 只连到:                              ║
║   → ROW_q输出(800,560)                                       ║
║   → Comparator.A(710,610)                                    ║
║                                                              ║

# =====================================================================
#  第三章: 错误后果分析
# =====================================================================

  当前逻辑:
    OBS_ROW.D = OBS_COL.Q + 0 = OBS_COL.Q
    → OBS_ROW 每个时钟被设为 OBS_COL 的值
    → 障碍物永远在 row = column 的对角线上

  同时:
    OBS_COL.D = OBS_SRC (random每周期)
    OBS_COL.EN = clock (每周期都使能)
    → OBS_COL 每个时钟变为新随机值
    → OBS_ROW 也跟随变为同一随机值

  结果:
    ┌──────────────────┐
    │ 周期1: col=3 → row=3 障碍物在(3,3)   │
    │ 周期2: col=7 → row=7 障碍物在(7,7)   │  ← 对角线跳跃
    │ 周期3: col=1 → row=1 障碍物在(1,1)   │
    │ ...                                   │
    └──────────────────┘

  正确逻辑应为:
    OBS_ROW.D = OBS_ROW.Q + 1
    → 障碍物从 row=0 开始, 每周期 row+1
    → 到达 row=15 时 AT_BOTTOM=1 → 新障碍物

  修复涉及3处改动 (在 model4 子电路内):

  ┌──────┬─────────────────────┬──────────────────────────────┐
  │ 改动 │ 当前(错误)           │ 应为                         │
  ├──────┼─────────────────────┼──────────────────────────────┤
  │  1   │ Adder.A ← OBS_COL.Q │ Adder.A ← OBS_ROW.Q         │
  │      │ 删: (470,610)→      │ 加: (670,610)→(670,530)→   │
  │      │     (500,610)→      │    (530,530)→(530,610)      │
  │      │     (530,610)       │                              │
  ├──────┼─────────────────────┼──────────────────────────────┤
  │  2   │ Adder.B = 0x0       │ Adder.B = 0x1               │
  │      │ Constant(490,630)   │ 修改value或替换为value=0x1   │
  │      │ 默认值=0            │                              │
  ├──────┼─────────────────────┼──────────────────────────────┤
  │  3   │ OBS_COL.EN = clock  │ OBS_COL.EN = AT_BOTTOM      │
  │      │ (每周期加载随机值)   │ (仅触底时加载新随机列)       │
