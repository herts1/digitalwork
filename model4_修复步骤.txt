# =====================================================================
#  第三章: 修复操作 (3步, 共删3条线, 加5条线, 改1个常量)
# =====================================================================

# ─────────────────────────────────────────────────────────────────
#  修复1: Adder.A 改接 OBS_ROW.Q (反馈回路)
#  目的: OBS_ROW.D = OBS_ROW.Q + B, 实现自增计数
# ─────────────────────────────────────────────────────────────────

  【删 D1】导线 (500,610)→(530,610)
    位置: 水平线, y=610, x从500到530
    作用: 切断 OBS_COL.Q → Adder.A 的错误连接
    注意: 只删这一段! (500,610)到(470,610)和(500,510)的线保留

  【加 N1】导线 (670,610)→(670,530)
    源:  [REG2] OBS_ROW.Q 输出引脚 (x=670, y=610)
    目标: 中间拐点 (670,530)
    路径: 从 (670,610) 垂直向上 80 格到 (670,530)

  【加 N2】导线 (670,530)→(530,530)
    源:  拐点 (670,530)
    目标: 拐点 (530,530)
    路径: 从 (670,530) 水平向左 140 格到 (530,530)

  【加 N3】导线 (530,530)→(530,610)
    源:  拐点 (530,530)
    目标: [ADD] Adder.A 输入引脚 (530,610)
    路径: 从 (530,530) 垂直向下 80 格到 (530,610)

  修复1效果:
    [REG2].Q(670,610) ──→ (670,530) ──→ (530,530) ──→ [ADD].A(530,610)
    ✅ Adder.A 现在接收 OBS_ROW 当前值


# ─────────────────────────────────────────────────────────────────
#  修复2: Adder.B 改为 1
#  目的: Adder = OBS_ROW + 1, 每周期行号+1
# ─────────────────────────────────────────────────────────────────

  【改 CON1】修改常量 [CON1] 的值
    位置: [CON1] Constant at (490,630)
    操作: 右键点击 → 属性 → Value → 输入 0x1 (或 1)
    当前: 0x0 (默认)
    改为: 0x1

  修复2效果:
    [ADD].B = 0x1
    [ADD].out = OBS_ROW.Q + 1 ✅


# ─────────────────────────────────────────────────────────────────
#  修复3: OBS_COL.EN 改为 AT_BOTTOM 控制
#  目的: 障碍物列只在触底时加载新随机值, 否则保持不变
# ─────────────────────────────────────────────────────────────────

  【删 D2】导线 (310,650)→(410,650)
    位置: 水平线, y=650, x从310到410
    作用: 切断 clock → OBS_COL.EN 的连接

  【加 N4】导线 (800,620)→(800,650)
    源:  [OUT3] AT_BOTTOM 输出引脚 (800,620)
    目标: 中间拐点 (800,650)
    路径: 从 (800,620) 垂直向上 30 格到 (800,650)

  【加 N5】导线 (800,650)→(410,650)
    源:  拐点 (800,650)
    目标: [REG1] OBS_COL.EN 引脚 (410,650)
    路径: 从 (800,650) 水平向左 390 格到 (410,650)

  修复3效果:
    [OUT3].AT_BOTTOM(800,620) ──→ (800,650) ──→ [REG1].EN(410,650)
    ✅ OBS_COL 只在 AT_BOTTOM=1 时加载新随机列

#  第五章: 修复后信号流图
# =====================================================================

  修复后 model4 内部逻辑:

  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │  [IN1] OBS_SRC(随机列) ──→ [REG1].D                         │
  │                               │                             │
  │  [OUT3] AT_BOTTOM ──→ [REG1].EN  (触底才加载)              │
  │                               │                             │
  │                         [REG1] OBS_COL                      │
  │                               │                             │
  │                               ├──→ [OUT1] COL_Q 输出        │
  │                                                             │
  │  ┌────────────────────────────┼──────────────────────┐      │
  │  │                            │                      │      │
  │  │  [REG2] OBS_ROW            │                      │      │
  │  │     │                      │                      │      │
  │  │     │ Q ──→ [OUT2] ROW_q 输出                     │      │
  │  │     │                                              │      │
  │  │     │ Q ──→ [ADD].A ──┐                            │      │
  │  │     │       [CON1]=1 ─┤                            │      │
  │  │     │                 │                            │      │
  │  │     │         [ADD] out = OBS_ROW + 1              │      │
  │  │     │                 │                            │      │
  │  │     │                 ▼                            │      │
  │  │     └──── [REG2].D ←──┘                            │      │
  │  │                                                    │      │
  │  │     [REG2].Q ──→ [CMP].A                           │      │
  │  │     [CON2]=15 ─→ [CMP].B                           │      │
  │  │                 │                                   │      │
  │  │         [CMP] out = (OBS_ROW == 15)                │      │
  │  │                 │                                   │      │
  │  │                 ▼                                   │      │
  │  │           [OUT3] AT_BOTTOM ──→ 到外部               │      │
  │  │                      │                              │      │
  │  │                      └──→ [REG1].EN (反馈)          │      │
  │  │                                                    │      │
  └─────────────────────────────────────────────────────────────┘

  工作流程:
    周期N:   OBS_ROW = K, AT_BOTTOM = (K==15)?
            OBS_ROW.D = K+1 (自增)
            OBS_COL.EN = AT_BOTTOM (触底才使能)
            若K==15: OBS_COL加载新随机值, OBS_ROW变为0
            否则:    OBS_COL保持不变, OBS_ROW变为K+1

  □ 进入 model4 子电路 (双击左侧项目树)
  □ 删除 D1: (500,610)→(530,610)
  □ 删除 D2: (310,650)→(410,650)
  □ 添加 N1: (670,610)→(670,530), 垂直
  □ 添加 N2: (670,530)→(530,530), 水平
  □ 添加 N3: (530,530)→(530,610), 垂直
  □ 添加 N4: (800,620)→(800,650), 垂直
  □ 添加 N5: (800,650)→(410,650), 水平
  □ 修改 CON1: Constant(490,630) 值改为 0x1
  □ 返回主电路, 启动仿真

  预期行为:
  - OBS_ROW 从 0 开始, 每个时钟周期 +1
  - OBS_ROW 到达 15 后跳回 0 (4bit自然回绕)
  - OBS_COL 在 OBS_ROW=15 时更新为新的随机值
  - AT_BOTTOM 在 OBS_ROW=15 时输出 1
  - ROW_q 输出 OBS_ROW 的当前值
  - COL_Q 输出 OBS_COL 的当前值
