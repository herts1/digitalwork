# =====================================================================
#  第二章: 寄存器引脚速查
# =====================================================================

  每个 Register 的 4 个引脚位置 (锚点为 rx,ry):

    ┌──────────────┐
    │              │
    │   RST 引脚    │  约 (rx+10, ry-10) 或北侧
    │   D 引脚      │  约 (rx-10, ry+30) 或西侧
    │   Q 引脚      │  约 (rx+30, ry+10) 或东侧
    │   CLK 引脚    │  约 (rx+10, ry+30) 或南侧 (三角形)
    └──────────────┘

  实际连线时以 Logisim 中绿色小圆点为准，点击引脚圆心接入。

# ─────────────────────────────────────────────────────────────────
#  区块一: 时钟分发 (W1~W3)
# ─────────────────────────────────────────────────────────────────

【W1】[CLK] → [R1] CLK
  源:  [CLK] Clock (100,60)
  目标: [R1] Register CNT1 (240,100), CLK引脚
  走线: (100,60)→水平→(200,60)→垂直→(200,130)→水平→(240,130)
  位宽: 1bit ✓

【W2】[CLK] → [R2] CLK
  源:  从拐点 (200,60) 分支引出
  目标: [R2] Register CNT2 (240,220), CLK引脚
  走线: (200,60)→垂直→(200,250)→水平→(240,250)
  位宽: 1bit ✓

【W3】[CLK] → [R3] CLK
  源:  从拐点 (200,60) 分支引出
  目标: [R3] Register CNT3 (240,340), CLK引脚
  走线: (200,60)→垂直→(200,370)→水平→(240,370)
  位宽: 1bit ✓

【W5】[RST] → [R2] RST
  源:  从拐点 (180,150) 分支引出

【W6】[RST] → [R3] RST

# ─────────────────────────────────────────────────────────────────

【W7】[R1].Q → [A1].A

【W9】[A1].out → [R1].D

# =====================================================================
#  第五章: 速度档位说明
# =====================================================================

  假设输入时钟 2Hz，每个计数器 4bit(0→15回绕):

  ┌──────────┬─────────┬─────────────┬──────────────┬──────────┐
  │ SPEED    │  MUX    │ 来源寄存器  │ bit0频率      │ 适合     │
  ├──────────┼─────────┼─────────────┼──────────────┼──────────┤
  │  00      │  in0    │ CNT1.Q      │  1 Hz        │  极快    │
  │  01      │  in1    │ CNT2.Q      │  0.0625 Hz   │  中速    │
  │  10      │  in2    │ CNT3.Q      │  0.0039 Hz   │  慢速    │
  │  11      │  in3    │ (悬空=0)    │  停止        │  暂停    │
  └──────────┴─────────┴─────────────┴──────────────┴──────────┘

  接线后用量: GAME_TICK[3:0] → Splitter(fanout=4) → 取bit0→模块CLK


# =====================================================================
#  第六章: 自检清单
# =====================================================================

  □ 布局: 同列器件X统一 (输入100, 寄存器240, 加法器380, MUX520)
  □ 布局: 同排器件Y统一 (R1=100, R2=220, R3=340)
  □ 布线: 全部走线水平/垂直, 拐点整数坐标
  □ 布线: 每线两端落在引脚绿点中心
  □ 位宽: 4bit→4bit (Q→Adder, Adder→D, Q→MUX, MUX→OUT)
  □ 位宽: 1bit→1bit (CLK, RST)
  □ 位宽: 2bit→2bit (SPEED→MUX.sel)
  □ 方向: 全部 output→input, 无输出互接
  □ 反馈: CNT1.Q→A1.A, CNT2.Q→A2.A, CNT3.Q→A3.A (各自独立)
  □ 常数: C1=0x1, 三个Adder共用
  □ 回绕: 4bit加法器 15+1=0 自动回绕, 无需额外逻辑
